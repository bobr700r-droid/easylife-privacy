Sociálník · Platné od 13. října 2026

Sociálník je osobní nástroj autora pro vlastní účty na sociálních sítích. Data jsou na jeho vlastním serveru (domácí NAS), ne u třetích stran. K Instagramu, Facebooku a Threads se připojuje jen přes oficiální přihlášení Mety a Threads (OAuth) – heslo appka ani server nikdy nevidí. Bez schválení v appce se nic nepublikuje. Nemá reklamy ani analytiku.

Přihlášení

Do appky se přihlašuješ přes Přihlásit se s Apple. Server dostane jen anonymní identifikátor tvého Apple ID (bez jména a e-mailu), aby pouštěl jen vlastníka. Relace je uložená v Klíčence zařízení.

Instagram a Facebook

Po přihlášení na stránce Mety server dostane přístupový token k tvé Facebook stránce a propojenému Instagramu s oprávněními jen pro publikaci a statistiky. Token je na serveru šifrovaný (AES-256-GCM) a do appky ani do jiných služeb se nikdy neposílá. Server čte jen údaje tvých vlastních účtů (název, počet sledujících, statistiky tvých příspěvků). Odpojením v Nastavení se token smaže a oprávnění u Mety odvolá.

Threads

Po přihlášení na stránce Threads server dostane přístupový token k tvému účtu Threads s oprávněními threads_basic, threads_content_publish, threads_manage_insights a threads_read_replies – jen pro publikaci tvých příspěvků a čtení jejich statistik (zobrazení, líbí se, odpovědi, reposty, citace, sdílení, počet sledujících). Token platí 60 dní, server ho před vypršením sám prodlouží. Je na serveru šifrovaný (AES-256-GCM) a do appky ani do jiných služeb se nikdy neposílá. Odpojením v Nastavení → Účty se token smaže. Když appku odebereš v nastavení Threads, server token smaže sám; když přes Threads požádáš o smazání dat, server smaže účet, token i statistiky z Threads a vrátí kód potvrzení.

Fotky

Fotky vybíráš sám ze systémového výběru Fotek nebo ze Souborů (appka vidí jen to, co vybereš). Zmenšená kopie se nahraje na tvůj server. Instagram, Facebook a Threads si ji při publikaci stáhnou z krátkodobého podepsaného odkazu (platí 30 minut).

AI (Claude)

Na návrh plánu, texty a týdenní report posílá server data značky, texty a vybrané fotky do Claude API (Anthropic). Anthropic data z API nepoužívá k trénování modelů. Měsíční výdaje mají tvrdý strop.

Mazání dat

Koncepty a fotky smažeš v appce, účty sítí odpojíš v Nastavení → Účty. Požadavek na smazání všech dat (i z Mety přes Nastavení → Aplikace a weby, z Threads přes Nastavení → Účet → Weby a aplikace) vyřídíme na info@luksafoto.cz.

Sdílení dat

Data neprodáváme ani nesdílíme pro reklamu nebo sledování. Obsah opustí aplikaci jinak jen tehdy, když ho sám odešleš tlačítkem Sdílet.

TestFlight

Privacy Policy

Sociálník · Effective October 13, 2026

Sociálník is the author's personal tool for his own social media accounts. Data lives on his own server (a home NAS), not with third parties. It connects to Instagram, Facebook and Threads only through the official Meta and Threads login (OAuth) – neither the app nor the server ever sees a password. Nothing is published without approval in the app. No ads or analytics.

Sign-in

You sign in to the app with Sign in with Apple. The server receives only an anonymous identifier of your Apple ID (no name or e-mail) so that it admits only its owner. The session is stored in the device Keychain.

Instagram and Facebook

After you log in on Meta's page, the server receives an access token for your Facebook Page and connected Instagram with permissions for publishing and insights only. The token is encrypted on the server (AES-256-GCM) and is never sent to the app or any other service. The server reads only data of your own accounts (name, follower count, insights of your posts). Disconnecting in Settings deletes the token and revokes the permission at Meta.

Threads

After you log in on the Threads page, the server receives an access token for your Threads account with the permissions threads_basic, threads_content_publish, threads_manage_insights and threads_read_replies – only to publish your posts and read their insights (views, likes, replies, reposts, quotes, shares, follower count). The token is valid for 60 days and the server renews it before it expires. It is encrypted on the server (AES-256-GCM) and is never sent to the app or any other service. Disconnecting in Settings → Accounts deletes the token. If you remove the app in your Threads settings, the server deletes the token itself; if you request data deletion through Threads, the server deletes the account, the token and the Threads insights and returns a confirmation code.

Photos

You pick photos yourself from the system Photos picker or Files (the app sees only what you pick). A downscaled copy is uploaded to your server. Instagram, Facebook and Threads download it at publishing time from a short-lived signed link (valid for 30 minutes).

AI (Claude)

For plan proposals, captions and the weekly report the server sends brand settings, texts and the selected photos to the Claude API (Anthropic). Anthropic does not use API data to train models. Monthly spending has a hard cap.

Deleting data

Delete drafts and photos in the app, disconnect networks in Settings → Accounts. Requests to delete all data (also from Meta via Settings → Apps and websites, from Threads via Settings → Account → Website permissions) are handled at info@luksafoto.cz.

Data sharing

We never sell data or share it for advertising or tracking. Content otherwise leaves the app only when you send it yourself with the Share button.

TestFlight

During TestFlight testing, Apple may pass on feedback you choose to send and anonymous crash reports according to your device settings.
